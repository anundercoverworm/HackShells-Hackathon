Collection Tracker

Collection Tracker is an application for keeping track of the value of collectible items. It lets you follow what your collection is worth and shows a chart of how an item's price changes over time.

Built by a team of three for the HackShells hackathon.

What it does
Keeps track of the value of collectible objects
Displays a price chart for each item
What was planned but not built

The app was also meant to connect to online marketplaces such as eBay and similar platforms, to pull real prices automatically. This feature is not implemented: eBay requires a verification period for API access that was longer than the hackathon itself, so the integration could not be completed in time. Prices are currently entered and tracked within the app.

Tech stack
Backend: Python
Frontend: HTML

Running the app
The repository includes a portable Windows build (CollectionTrackerPortable.zip) and launcher scripts. See README_PORTABLE.txt for how to run it.

Status
Hackathon project. The core tracking and price chart work; marketplace integration was left out.
